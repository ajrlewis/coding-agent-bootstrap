# Supabase Preset

- Treat Supabase as PostgreSQL plus managed platform services.
- Keep local and remote schema workflows explicit.
- Review row-level security policies and auth assumptions when touching data access.
- Do not commit service role keys, database passwords, or project secrets.
- Keep generated types, migrations, and local config in sync with the repository's chosen workflow.
- Record verified Supabase commands in `.agents/COMMANDS.md`.
