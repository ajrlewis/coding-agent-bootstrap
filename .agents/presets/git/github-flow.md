# GitHub Flow Preset

Use focused branches and pull requests.

- Branch from `main`.
- Do not push directly to `main`.
- Keep changes scoped to one task or closely related set of changes.
- Make focused commits with clear messages.
- Keep the branch current enough to avoid avoidable conflicts.
- Push the branch and open a pull request.
- Do not force-push shared branches or rewrite shared history casually.
- Inspect CI, review comments, and required checks before considering work complete.

If maintainer policy differs, record the project-specific workflow in `.agents/WORKFLOW.md`.
