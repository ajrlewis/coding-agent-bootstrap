# Session Archive

Move completed active briefs here as dated, descriptive Markdown files, for example `2026-09-27-add-export.md`.

Preserve the completed brief and add, when known, its completion status, completion date, pull request or equivalent review identifier, merged commit, concise outcome, and verification outcome. An archive is historical evidence only and cannot override current code, tests, architecture, product specifications, or `.agents/sessions/ACTIVE.md`.

Move durable facts learned during the work into their natural canonical files, such as `.agents/ARCHITECTURE.md`, `.agents/COMMANDS.md`, or product documentation. This README keeps the managed archive directory present; it is not a completed session record.
